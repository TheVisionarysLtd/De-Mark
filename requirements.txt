# --- torch: enables the AI sparkle DETECTOR and LaMa inpainting -------------
# torch powers two things: (1) the neural sparkle detector (weights ship in
# wmr/weights/, ~2 MB) that finds the mark on busy backgrounds, and (2) LaMa
# inpainting for seamless, palette-adapting fills. Both fall back gracefully if
# torch is absent (classical detector + OpenCV fill).
#
# Install it in two steps (do NOT add these as plain requirements — the wrapper
# pins an old numpy that tries to build from source and fails):
#   pip install torch --index-url https://download.pytorch.org/whl/cpu   # ~124 MB CPU build
#   pip install --no-deps simple-lama-inpainting
# The LaMa model (~200 MB) downloads automatically on first use.
# (Works on Python 3.14: torch 2.13.0 ships a cp314 wheel.)
